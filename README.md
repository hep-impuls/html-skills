# HTML Skills für Lehrpersonen

Willkommen. Dieses Repository enthält sofort nutzbare Bildungs-HTML-Beispiele und ein wiederverwendbares Codex-Skill-Paket für Lehrpersonen.

## Worum es in diesem Repo geht

Dieses Projekt ist eine kleine öffentliche Ressource für Lehrpersonen, die:

- verschiedene Stile von unterrichtstauglichen HTML-Seiten erkunden möchten
- bewährte Seitenstrukturen für Lektionen und Arbeitsblätter wiederverwenden möchten
- neue Seiten mit einem skillbasierten Workflow erstellen möchten

Die Beispiele orientieren sich an schweizerischen Berufsbildungs-/ABU-Kontexten, lassen sich aber auf andere Fächer übertragen.

## Struktur des Repositories

- `examples/type_A.html`  
  Interaktives Lektionenformat (Slides, Aktivitäten, Punkte, Druckansicht).
- `examples/type_B.html`  
  Druckorientiertes A4-Arbeitsblatt-/Dokumentformat.
- `examples/type_C.html`  
  Scrollbares Info-Dossier-Format (medienreich, screen-first).
- `skill/edu-html-generator/edu-html-generator/SKILL.md`  
  Hauptanleitung des Skills zur Generierung vollständiger Bildungs-HTML-Seiten.
- `skill/edu-html-generator/edu-html-generator/references/`  
  Komponenten-Referenzen für die Seitentypen A, B und C.
- `edu-html-generator.zip`  
  Paketierte Version des Skills für einfaches Teilen/Importieren.

## So verwendest du das Repo

1. Öffne eine Datei aus `examples/` im Browser, um das jeweilige Format anzusehen.
2. Wähle das Format passend zu deinem Unterrichtsziel:
   - interaktive Schülerarbeit -> Typ A
   - druckbares Arbeitsblatt/Broschüre -> Typ B
   - Überblick/Info-Dossier -> Typ C
3. Nutze die Skill-Dateien in `skill/...` als Vorlage, um neue themenspezifische Seiten zu erzeugen.

## Für wen ist das gedacht?

- ABU- und Berufsfachschul-Lehrpersonen
- Sprachlehrpersonen mit interaktiven oder druckbasierten Materialien
- Lehrpersonen, die mit Single-File-HTML-Lernmaterialien arbeiten möchten

## Hinweise

- Die Beispiele sind eigenständige HTML-Dateien (kein Build-Prozess nötig).
- Einige Beispiele laden Webfonts und CDNs; für volle Darstellung kann Internetzugang nötig sein.
- Du kannst dieses Repo forken und für deine Klassen, Themen und Niveaus anpassen.
