Type A Interaktive Lektion

Folienbasiert mit Quiz, Drag & Drop, Vokabelkarten und Ergebnisfolie. Dark/Light-Toggle, Tastaturnavigation, Speicherung per localStorage.

Type C Info-Dossier

Type E Adaptiver Lernpfad

Type F Fallstudie

Type G Vokabeltrainer

Type H Concept Map

SVG-Leinwand mit Drag & Drop. Begriffe setzen, verbinden, beschriften und drucken. Modi: frei, gefuehrt oder Lehreransicht.

Type I Experiment-Protokoll

Type J Timeline
